# AdventureWorks BI Dashboard 📊

This repository contains a complete Business Intelligence solution for AdventureWorks, a global manufacturing company specializing in cycling equipment and accessories. Built using Power BI Desktop, this project helps track KPIs, analyze product performance, compare regional data, and identify high-value customers.

---

## 🔍 Project Overview

**Company:** AdventureWorks  
**Role:** Business Intelligence Analyst  
**Tools Used:** Power BI Desktop, DAX, Power Query, CSV  

---

## 📈 Key Business Insights

### Executive Summary
- 💰 Revenue: $24.9M | 🏆 Profit: $10.5M | 📦 Orders: 25.2K | 🔁 Return Rate: 2.2%
- 🚲 Top Ordered Category: Tires & Tubes
- 👕 Most Returned Category: Shorts

### Regional Performance
- Active markets include USA, UK, Germany, Australia, and more.

### Product Deep Dive
- **Water Bottle – 30 oz.** showed a **230% profit growth**.
- High-margin product suitable for targeted marketing campaigns.

### Customer Analysis
- 📊 17.4K unique customers, $1,431 average revenue/customer.
- Skilled manual and professional customers are key segments.

3. Refresh the data source or relink CSVs from the `data/` folder.
4. Explore and customize as needed.
